04 / THE OBSERVED DWELL LEDGER

Every duration has an evidence trail.

EpisodeVessel / classReported stateStart UTCEnd UTCMinutesEnd reason

Minimum span 20 minutes; speed ≤0.5 knots; consecutive reports ≤15 minutes apart; each position within 500 metres of the episode’s first report. State changes, radius limits and coverage gaps split episodes. Boundary episodes can continue outside the observed window.

05 / SENSITIVITY CHECK

How much does the gap rule matter?

Maximum gapEpisodesObserved hours

Same reports, speed, radius and duration rules; only the allowed gap changes. A more permissive rule can merge periods whose intervening activity is unknown. Sensitivity uses all vessel classes and states.

06 / REPRODUCIBLE SHIPPING ANALYTICS

Built for an honest handoff.

A streamed data pipeline screens nationwide reports, validates coordinates and vessel types, rejects conflicting timestamps, and builds reproducible dwell episodes.

Read the method and limitations ↗

One historical holiday, one study area and incomplete AIS coverage cannot establish port efficiency or congestion. Status is self-reported. No live tracking, identity lookup, commercial intelligence service or navigation aid.
